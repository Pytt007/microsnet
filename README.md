# MicroSnet Web Application

Plateforme digitale premium pour la gestion des démarches juridiques et administratives en Côte d'Ivoire.

## Technologies Utilisées

- **Frontend**: Vite, React, TypeScript
- **Styling**: Tailwind CSS, Shadcn UI
- **Icons**: Lucide React
- **Animations**: Framer Motion / Tailwind Animate

## Installation Locale

Assurez-vous d'avoir Node.js installé sur votre machine.

```sh
# 1. Cloner le repository
git clone <votre-url-git>

# 2. Entrer dans le dossier
cd microsnet-main

# 3. Installer les dépendances
npm install

# 4. Lancer le serveur de développement
npm run dev
```

## Structure du Projet

- `src/components`: Composants UI réutilisables.
- `src/pages`: Pages de l'application (Accueil, Services, Dashboard, etc.).
- `src/hooks`: Hooks personnalisés pour l'authentification et le chargement de fichiers.
- `src/assets`: Logos et images de la marque.
